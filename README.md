# 雅中之思 · IELTS Learning Studio

一个把「今天学什么」直接摊在首页的雅思学习空间。打开就是今日范文、今日单词、今日听力、今日口语和今天该做的任务，不用自己在资料里翻。

**无需注册登录**：打开就能学，所有进度保存在本设备浏览器（localStorage），换设备时在「个人中心 → 导出/导入备份」迁移。

线上地址：https://ielts-station-86055.app.workbuddy.host/?sharecode=MUZ3NY7BPH

---

## 它解决什么问题

大多数雅思备考工具是「素材仓库 + 题库」：内容很多，但每天要自己决定学什么，决策成本比学习本身还高，第三天就放弃了。

这个项目把决策做掉：**按你的目标分、考试日期、每天可投入时长排出当天任务，并且每天自动换一批内容和一段话。** 首页不是导航页，是一个每天更新的私人学习空间。

## 功能

### 今日学习空间（首页）
- 今日大作文 / 小作文：点进去是完整教学包，不是一篇范文了事
- 今日重点单词：按天轮换 5 个，优先你还没掌握的
- 今日词根：一组同根词（≥3 个才成组），配词根逻辑
- 今日听力 / 今日口语：按天轮换，点进去直接开始练
- 今日任务 + 提醒：文案随时间变（晚上 10 点后没做完会说「挑最小的一件做完就睡」）
- 今日总结：新词、复习次数、时长、完成度 + 明天建议
- 学习成就：12 个里程碑自动点亮，不用打卡
- 每天学几个新词自己定（5–100 个），选完全自动给出预计完成天数、复习负荷和耗时提醒，不用跟着固定节奏走
- 每日一段话：40 条语录按状态选场景（逾期→拖延时、考前 14 天→焦虑时、晚 9 点没开始→想放弃时、连学 3 天今天没动→倦怠时），另配 8 篇原创学习故事

### 词汇
- 3000+ 词覆盖全书 20+ 章，含英/美双音标、双发音音频、词根记忆提示、雅思语境例句
- **词根记忆**：拆前缀 / 词根 / 后缀，给「为什么是这个意思」的逻辑链，再列出同根词家族
- 词汇页点进去直接学，「下一词」一键切换，不用登录、不用确认
- SM-2 变体间隔重复：1/2/4/7/14/30/60 天阶梯，答错 8 分钟后重来并标记为错词
- 拼写诊断：最长公共子序列做字符级对齐，指出你多写/漏写了哪个字母（`envirnment` 少一个 `o`）
- 五种训练：拼写、听音拼写、中译英、英译中、词根猜词

### 听写 · 拼词闯关 · 手工柜
- **每日听写**：10 个词（错词优先，混到期词和学过的词），只给发音和中文，写出英文；逐字母 diff 指出错在哪，结果自动进复习队列
- **拼词闯关**：按单元拆成关卡（每关 8 词），听音拼词、三颗心、全对三星；过一关解锁下一关，星星存本地
- **手工柜**：每个单元是一件手作（织围巾 / 缝布包 / 拼抱枕……20+ 件各不相同）。学一个词 = 织一针/缝一格/拼一块，答错一次留一根红色线头；整单元学完成品进柜子，点开能看「线头清单」——哪个词错了几针一目了然

### 听力
- 精听八步：盲听 → 逐句听写 → 词级 diff 比对 → 句法/语音解析 → 错因归类 → 记录
- 略听模式：整段连播 + 理解题 + 折叠原文
- 9 类错因标签，自动猜你错在哪

### 写作
- 范文精读：段落功能拆解、可迁移句型、高分信号、常见失分点
- Task 1 句型库、Task 2 五种题型结构、衔接词库、话题词汇
- 计时写作 + 字数统计，保存到学习记录

### 学习计划 / 学习记录 / AI 助手
- 学习计划：目标分（5.0–9.0 全档可选）、考试日期、每日时长、每天新词数（5–100 自选）→ 本地生成每日任务，随时调整
- 学习记录：14 天柱状 + 30 天热力图、错词档案、听力错因画像、作文列表
- AI 助手：批改作文、讲词、润色口语、听力错因分析、复盘；支持流式对话，**AI 服务不可用时自动切换本地助教**（讲词、排计划、错词复盘、作文初诊、模板语检查，全部离线可用）

## 技术

纯静态站点，无构建步骤，无账号体系：

```
index.html          入口（hash 路由）

js/cloud.js         仅保留 LLM 流式调用（可选；失败自动降级）
js/store.js         数据层：localStorage 持久化、SRS 调度、统计、任务、备份导入导出
js/tutor.js         本地助教：讲词 / 排计划 / 错词复盘 / 作文启发式诊断（离线可用）
js/daily.js         每日内容轮换、成就、总结、范文详情页
js/game.js          拼词闯关（关卡制拼写游戏）
js/craft.js         手工柜（单元 → 手作进度可视化）
js/dashboard.js     首页（今日学习空间）
js/vocab.js         词汇中心 / 学习会话 / 听写 / 训练
js/listening.js     精听八步与略听
js/writing.js       范文精读 / 题型 / 句型 / 动笔练习
js/reading.js       阅读与同义替换
js/speaking.js      口语三个 part 与跟读
js/plan.js          学习计划生成
js/records.js       学习记录与热力图
js/ai.js            AI 对话（云端 + 本地助教兜底）
```

- 音频：Edge TTS 批量生成（`en-GB-SoniaNeural` / `en-GB-RyanNeural` / `en-US-AriaNeural`）

## 数据是怎么来的

词库源自刘洪波《雅思词汇真经》的扫描版 PDF。这份 PDF 是**纯图片扫描件，没有文字层**（pypdf 提取结果为 0 字符），所以走了这条路：

1. 用 pypdf 逐页导出内嵌图片
2. 视觉转录：逐页识别词条、音标、释义、例句、记忆法，处理跨栏跨页的断句
3. 第 1–3 章的词做了二次扩写（美式音标、英文释义、词根拆解、雅思语境第二例句、同义反义、词族）
4. 页码校准：以实读页脚为准（正文印刷页码 = PDF 页 − 9）

**已完成全书正文转录：3100+ 词、20+ 个主题章节。**

关于准确性做了两件事：
- 词根拆解只写可查证的词源，拆不出来的明确标注「整体记忆」，**不编造词源**
- AI 反馈只作练习参考，**不做官方评分**，不伪造分数
